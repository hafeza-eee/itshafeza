# Mst Hafeza Khatun — Illustrated Cartoon-Village Portfolio

## Run locally
1. Extract the ZIP file.
2. Keep `index.html`, `style.css`, `script.js`, `cv.pdf`, and the `assets` folder together.
3. Open `index.html` in a modern browser. Internet is only needed for the Google Fonts.

## Included
- Full custom portfolio layout inspired by a cozy cartoon/anime village mood
- Fixed desktop sidebar and mobile navigation
- Dreamy illustrated village hero with soft blur and overlay
- Profile portrait, education, academic project, community involvement, skills, hobbies, contact links
- Light/dark theme toggle and linked CV PDF

## Customize
- Replace `assets/profile-photo.jpeg` to update the profile picture.
- Replace `assets/village-landscape.png` to change the illustrated background.
- Edit content in `index.html`.
- Replace `cv.pdf` when a newer CV is available.

Some descriptions remain general where specific accomplishments or project links were not supplied.
